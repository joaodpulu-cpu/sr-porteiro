# Sr. Porteiro 🚪

O Sr. Porteiro é um aplicativo de proteção contra chamadas indesejadas.

A ideia é permitir que o usuário tenha controle sobre quem pode ligar para seu celular.

## Objetivo

Permitir chamadas de contatos autorizados e bloquear chamadas indesejadas.

## Projeto

Este é o início do desenvolvimento do Sr. Porteiro.
